# PRD：F1–F12 自定义按键组合映射

- **来源**：用户对话需求（2026-11-21）
- **状态**：进行中

## 1. 要改什么及为什么

### 背景与目标
TriDog 当前仅监听修饰键单击（左 ⌘ / 右 ⌘ / ⇧）来快速切换中/日/英输入法。用户希望增强 TriDog，当按下 `F1`～`F12` 功能键时，可将其拦截并映射为自定义的按键组合（例如 `⌘C`、`⌃⌥Space`、`⇧⌘4` 等）。

### 变更内容
1. **事件拦截与重映射引擎**：
   - 将 `CGEventTap` 从只读 `.listenOnly` 升级为可拦截修改的 `.defaultTap`（需要「辅助功能 / Accessibility」权限）。
   - 监听 `.keyDown`（及 `.keyUp` 防残余/按键重复），当检测到 `F1`–`F12` 按下且已配置有效映射时：
     - **触发条件**：仅当不带 `⌘` / `⌥` / `⌃` / `⇧` 修饰键时触发（允许携带 `Fn` 修饰键 `.maskSecondaryFn`，以兼容 Mac 笔记本需按 `Fn + F1` 触发标准功能键的场景）。
     - 吞掉原始 `F1`–`F12` 事件（回调返回 `nil`），避免系统或前台应用同时响应原按键。
     - 合成并发送目标按键组合的 `keyDown` / `keyUp` `CGEvent`（带目标修饰键掩码），并避免自身合成的事件被 event tap 递归捕获。
   - **权限引导**：当未授予辅助功能权限或 event tap 创建失败时，菜单栏给予明确提示与快捷跳转（「系统设置 → 隐私与安全性 → 辅助功能」）。
2. **图形化配置界面（按键映射设置窗口）**：
   - 菜单栏新增「F1–F12 按键映射设置…」菜单项（支持中/日/英三语）。
   - 打开原生 macOS 窗口，列出 `F1`～`F12` 共 12 行：
     - 每行包含：键名（`F1`–`F12`）、启用开关（Checkbox）、快捷键录入按钮（点击后进入录入状态，按下任意「非单纯修饰键」的按键或组合键即可保存；按 `Esc` 可取消录入）、清除按钮。
     - 配置持久化到 `UserDefaults`。
   - 为避免在录入目标快捷键时被正在生效的 `F1`–`F12` 映射干扰，快捷键录入器处于录入状态时暂停触发功能键重映射。
3. **诊断日志兼容**：
   - 若开启「记录诊断日志」，记录 F1–F12 映射触发（仅记录源键名与目标按键描述，不记录用户输入内容）。

## 2. 边界（明确不要改什么）
- **不改现有输入法快切逻辑**：左 ⌘、右 ⌘、左/右 ⇧ 单击切换中/日/英输入法及 CJKV 焦点刷新、诊断日志、隐藏图标、开机自启等既有行为保持不变。
- **不支持多步宏序列**：本次仅支持「单个按键 + 可选修饰键组合」，不做延时宏或多键连发。
- **不拦截带修饰键的 F1–F12**：例如 `⌘F1`、`⇧F1` 等保留原样透传给系统/应用。
- **不改动 `build.sh` 与现有证书默认逻辑**：构建时通过 `SIGN_IDENTITY="Apple_self_dev"` 签名。

## 3. 完成标准
1. 使用 `SIGN_IDENTITY="Apple_self_dev" ./build.sh` 编译无警告/无错误，生成 `build/TriDog.app` 且签名有效。
2. 菜单栏可打开「F1–F12 按键映射设置…」窗口，能够为任意 F1–F12 录入自定义按键组合、单独开关、清除并持久化（重启后保留）。
3. 实际运行验证：按下已配置的 F1–F12（含 `Fn + F1–F12`）时，原 F 键不会触发，目标按键组合正确生效；按下带 `⌘/⌥/⌃/⇧` 的 F 键或未配置/关闭的 F 键时，原样透传。
4. 现有修饰键单击切换输入法功能正常工作，无回归。
5. PRD 文档末尾补充「已实现 + commit 号」。
